## <a id="dec-001"></a>DEC-001. Mobile web app first, native deferred

Status **accepted**. Evidence user.

Six weeks, one builder, two platforms otherwise. Camera access from the browser is enough. Native reconsidered when retention after two trips is known.

Alternatives considered: Native iOS and Android; Telegram bot; Desktop site.

Affects: [REQ-002](REQUIREMENTS.md#req-002), [REQ-004](REQUIREMENTS.md#req-004), [TASK-002](DELIVERY.md#task-002).

## <a id="dec-002"></a>DEC-002. Beachhead is the allergy traveler, not all travelers

Status **accepted**. Evidence user.

Sharpest pain, reachable communities, the builder is one of them.

Alternatives considered: All travelers; Vegetarians and vegans abroad.
